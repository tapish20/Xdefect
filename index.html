📄 Executive Research Summary (RQ1 - RQ4)

RQ1 (Within-Project Efficacy): Tree-based ensemble classifiers (Random Forest AUC = 0.831) statistically significantly outperform baseline Logistic Regression (AUC = 0.762, p < 0.05).

RQ2 (Feature Stability): Static OO metrics (LOC, WMC, RFC, Fan-Out) exhibit high cross-project ranking stability (r = 0.391, τ = 0.287), whereas process churn metrics are domain-specific.

RQ3 (Cross-Project Generalization): Zero-shot cross-project evaluation suffers a ~13.7% generalization drop due to domain shift, but static structural metrics provide a more resilient transfer baseline.

RQ4 (Traceable Recommendations): Coupling dynamic P75 thresholds with SHAP attributions delivers 100% feature-to-recommendation auditability.
